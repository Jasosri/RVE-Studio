RVE Studio 1.0 — START HERE
=====================

RVE Studio: composite cellular core design. Strain-energy homogenisation of laminated-composite cellular cores,
reliability rating of the wall model, FE design & validation with mesh-convergence verdicts, design databases
and multi-objective screening.

WINDOWS
-------
1. Install 64-bit Python 3.10 or newer (python.org).
2. Extract the archive and open the RVE Studio folder.
3. Double-click install_windows.bat (once).
4. Double-click START_RVE_STUDIO.bat.
If the window does not open, run diagnose_startup.bat.

ANY PLATFORM
------------
  pip install .            then   rvestudio-gui      (GUI)   or   rvestudio --help   (command line)

FIRST CHECKS
------------
  rvestudio benchmark                          84/84 benchmark values within 0.3 % (original model)
  rvestudio benchmark --wall-beam timoshenko --bending twist-corrected
  python -m pytest
